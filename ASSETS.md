# Asset provenance

All assets in this project are original SVG artwork created for this implementation. No external photographs, fonts, icons, or libraries are loaded by the website.

- `dist/assets/chicago.svg`: original stylised Chicago riverfront and skyline illustration, with architectural forms inspired by the city's skyline. It is an illustration, not a photograph or an exact architectural survey.
- `dist/assets/logo-mark.svg`: original abstract upward arrow mark for this design proposal. It is not represented as a recovered or verified corporate logo.
- `dist/assets/favicon.svg`: original favicon based on the same upward motif.
- Interface line icons are drawn in the SVG symbol definitions in `dist/index.html`.

Typography uses system fonts already installed on the visitor's device. These original assets are included in the source ZIP for use and modification with this website.
